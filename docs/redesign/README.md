# 다시 기획: 당신만 그런 게 아니었어요

> "오늘 당신만 그런 게 아니었어요. 지구 반대편에도 당신 같은 하루를 보낸 사람이 있고, 당신은 그 사람과 원래 이어져 있었어요."

물건은 주인공이 아니라 증거(실)다. 출발점은 **오늘의 나(마음)**이고, 하루 한 번 저녁에 1분 동안 한 사람을 만난다.
카드 수집·희귀도·퀴즈·세트·마을·파츠 캐릭터는 쓰지 않는다.

## 시안

`docs/redesign/mockups/*.dc.html`. 브라우저로 열면 대략 보인다(그림은 안 나온다).
`{{…}}`, `<sc-for>`, `<sc-if>`, `class Component extends DCLogic`는 시안 도구 문법이다. 레이아웃·크기·색·문구만 참고하고, 앱에서는 Vue로 새로 만든다.
`/_blob/…` 그림은 장면 그림(public/scenes/<장면 id>.webp)으로 바꾼다.

| 순서 | 시안 | 화면 |
|---|---|---|
| 1 | V2Mood | 오늘 하루, 어땠어요? 에너지 × 편안함 네 칸 위의 마음 8개 |
| 2 | V2Item | 오늘 손에 닿은 물건은요? 입력 + 자주 고르는 것 |
| 3 | V2Thread | 같은 순간, 다른 시각에서: 24시간 띠 위 나(서울)와 그 사람의 지금 시각, 실이 이어지며 거쳐 온 손이 점으로 |
| 4 | V2Person | 그 사람의 오늘: 장면 그림(그곳 시각으로 물든), 머리말, 제목, 이야기, 이름·일·지금은 아마 |
| 5 | V2Reply | 한마디 건네기 → 실을 묶었어요(매듭 애니메이션) |
| 6 | V2Map | 나와 이어진 사람들: 나를 가운데 두고 실제 방향·거리로 놓은 별자리 + 날짜별 목록 |
| 공유 | V2Quote | 1080×1350 인용 카드 |

## 디자인 기준

- 바탕 #FFFFFF, 면 #F5F6F8, 글씨 #14161A, 보조 글씨 #6B7079, 흐린 글씨 #8A8F98, 선 #E8EAEE
- 주 버튼: 높이 56, 둥글기 16, 바탕 #14161A, 글씨 흰색 17/700. 보조 버튼 바탕 #F1F2F5
- 글꼴: Noto Sans KR 하나. 13 / 15 / 17 / 22 / 26(제목 700, 자간 -0.01em). 이야기 본문 16, 줄간격 1.8
- 여백: 위 56~64, 양옆 24, 아래 32. 글자가 화면 맨 위·맨 아래에 붙지 않게
- 강조색은 따로 없다. **실의 색 = 오늘 고른 마음의 색**. 화면의 점·실·머리말이 그 색을 쓴다
- 장식(그림자·그라데이션 카드·테두리 상자)은 쓰지 않는다. 여백과 글자 크기로 위계를 만든다

## 한 사람 고르기

1. 물건 → 재료(지금 매칭 그대로) → 첫 재료의 경로 사람들(출발지 변형 포함, 지금 timeline 규칙).
2. 그 경로에서 이야기(stories.ts)가 있는 사람 중, **아직 안 본 편 가운데 오늘의 마음 태그가 붙은 편**이 있는 사람을 고른다. 여럿이면 덜 만난 사람, 그다음 출발지에 가까운 사람.
3. 없으면 같은 칸(에너지·편안 같은 쪽)의 마음 태그 편 → 그래도 없으면 그 경로에서 이야기가 있는 아무나의 다음 편.
4. 경로에 이야기가 있는 사람이 없으면: 핵심 인물 규칙(시작한 손)의 사람을 카드 문구로 보여 주고, 제목에 마음을 지어 붙이지 않는다("오늘 당신의 ○○이 지나온 길 위의 사람이에요").
5. 편은 사용자에게 몇 편인지 보이지 않는다(지금 규칙 그대로). 본 편 수는 keyMeets 대신 이 흐름에서 센다.

## 화면 문구

- 4번 머리말(마음 색): "오늘 당신의 {물건}이 지나온 길 위의 사람" (받침에 따라 이/가)
- 4번 제목: "{이름}도 오늘,\n{제목 꼴}." 2단계 3·4번으로 고른 경우에도 같은 꼴(이야기는 지어낸 것이라는 안내는 지금처럼 한쪽에 작게)
- 같은 사람을 다시 만나면 이야기 위에 한 줄: "지난번엔 당신도 {기억 문장 꼴} 했죠." + 지난번 건넨 한마디가 있으면 "(당신이 건넨 말: 저도 오늘 그랬어요)"
- 3번 문장: "지금 서울은 {시각}, {장소}는 {시각}. {N}시간 떨어진 그곳까지, {M}명의 손이 당신의 {물건}을 이어 주었어요." 같은 시간대면 "같은 시각, {M}명의 손이…"
- 5번 한마디: 저도 오늘 그랬어요 · 고생 많았어요 · 내일은 나을 거예요 · 직접 쓸게요(40자). 좋은 마음(glad·excited·proud)이면 저도 오늘 좋았어요 · 축하해요 · 오늘 같은 날이 또 오길

## 저장

- 하루 기록: 날짜(서울), 마음 id, 한 줄(선택), 물건 이름, 만난 사람 id, 본 편 번호, 건넨 한마디.
- **한 줄은 기기(localStorage)에만** 남긴다. 서버 동기화·로그·공유 어디에도 보내지 않는다. 서버에는 마음 id·물건·사람·편·한마디(고른 문구 번호, 직접 쓴 말은 보내지 않음)만.
- 하루 한 번: 오늘 기록이 있으면 첫 화면은 오늘의 결과(4번 요약)와 "내일 저녁에 또 만나요".
- 예전 저장값(카드·마을·여정)은 지우지 않는다. 화면에 쓰지 않을 뿐이다.

## 나와 이어진 사람들

- 서울(37.57, 126.98) 기준 방위각·대권 거리. 반지름 = 26 + 124 × log(1 + d/300) / log(1 + 12000/300). 1,000·5,000·10,000km 동심원.
- 서울·한국 안 사람은 가운데 가까이(반지름 22) 고정 각도로 흩어 놓는다. 바다 위(sea)는 북위 5°, 동경 85°로 둔다.
- 실 색 = 그날의 마음 색, 오래된 실일수록 흐리게. 아래에 날짜·이름·장소 목록. 누르면 그날의 4번 화면.

## 공유

- 새 공유 종류: 오늘의 실. 지금 share.ts 규칙(토큰·TTL·관리 키, 복구 코드·사용자 id 넣지 않기) 그대로.
- OG 이미지는 V2Quote: 날짜·마음(색 점)·장면 그림·"오늘 나와 같은 하루를 보낸 사람"·"{장소}의 {이름}"·인용(그 편의 첫 문장)·매듭 진 실·"{물건}으로 이어진 사람".
- 링크를 연 사람은 "당신의 오늘은 어땠어요?"(1번 화면)로 바로 시작한다.

## 모두의 오늘

- 서버에는 그날 마음 id별 숫자만 센다(지금 today.ts·스냅샷 방식 재사용). 5번 화면: "오늘 {마음}던 사람 {N}명이 지구 곳곳의 누군가와 실을 묶었어요."
