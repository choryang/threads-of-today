# 앱·노래 길 사람 카드 검토 표

new-paths-draft.md "8. 앱 하나", "9. 노래 한 곡", "공통 칸"을 데이터로 옮기기 전 초안이에요. 고칠 문구·이름을 알려 주면 그대로 반영해서 넣어요.

## 물건과 길

| 물건 | 재료(길) | 끝 사람 |
|---|---|---|
| 앱 (앱, 어플, 메신저, 배달 앱 …) | ★앱 만들기 + ★인터넷 | 고객센터 상담원 (지금 있는 사람) |
| 노래 (노래, 음악, 음원, 케이팝 …) | ★노래 만들기 + ★인터넷 | 없음 (인터넷 다음이 바로 '나') |

- 화면에는 회사·서비스 이름을 쓰지 않아요. "카톡"처럼 입력해도 화면에는 "앱"으로.
- ★인터넷은 앱과 노래가 같이 지나는 길이에요(나중에 영화·드라마도): 데이터센터 기술자 → 해저 케이블 수리선 선원 → 기지국 엔지니어.
- 노래는 끝에 건네주는 가게 사람이 없어요. 걷기에서 인터넷 칸 다음에 바로 "나"가 나와요.

**앱 만들기**: 기획자 → UX 리서처 → UI 디자이너 → 앱 개발자(호찌민) → 서버 개발자 → QA 테스터(하노이) → 현지화 담당 → 앱 마켓 심사원(미국) → 신고 검수원(춘천)
**노래 만들기**: 트랙메이커(노르웨이 트론헤임) → 탑라이너 → 작사가 → 편곡자 → 세션 연주자 → 보컬 디렉터 → 녹음 엔지니어 → 믹싱 엔지니어(미국 버지니아비치) → 마스터링 엔지니어(미국 뉴저지) → 앨범 아트 디자이너 → 음원 유통 담당
**인터넷**: 데이터센터 기술자(안산) → 해저 케이블 수리선 선원(바다 위) → 기지국 엔지니어(서울)

칸 사이 변신:
- 앱: 아이디어 → 기획서 → 사용성 테스트 기록 → 화면 시안 → 앱 코드 → 서버와 이어진 앱 → 테스트 빌드 → 여러 언어로 된 앱 → 심사 통과한 앱
- 노래: 코드와 박자 → 비트 → 데모 → 가사 붙은 데모 → 편곡 → 악기 녹음 → 보컬 녹음 → 믹스 → 마스터 음원 → 등록된 음원
- 인터넷: 데이터 → 서버 속 데이터 → 바다 밑 빛 신호 → 전파

## 사람 (새로 23명)

이름 옆 *는 해외 사람 중 이름 순위 출처를 아직 찾지 못한 후보예요(한국 사람은 평범한 한국 이름으로 정했어요).

### 앱 만들기

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| app-planner | 기획자 · 승우 | 성남 판교 | 무엇을 왜 만들지 정하고, 기능을 하나씩 적어 순서를 매겨요. 오늘 누른 버튼도 이 사람의 목록에서 시작했어요. | 회의실에서 다음 기능을 정하고 있을 거예요 · 평일 | |
| ux-researcher | UX 리서처 · 다은 | 서울 | 사람들에게 시안을 직접 써 보게 하고, 어디서 손이 멈추는지 옆에서 적어요. | 사용자 인터뷰 기록을 정리하고 있을 거예요 · 평일 | 다섯 명만 써 보게 해도 문제의 약 85%를 찾아요 (Nielsen Norman Group 2000) |
| ui-designer | UI 디자이너 · 재원 | 서울 | 버튼 크기와 글자, 색을 정해 화면을 그려요. 손가락이 닿기 쉬운 자리를 찾느라 몇 번이고 옮겨 봐요. | 버튼 자리를 이리저리 옮겨 보고 있을 거예요 · 평일 | |
| app-developer | 앱 개발자 · 린* | 베트남 호찌민 | 화면 시안을 휴대폰에서 돌아가는 코드로 옮겨요. 동료가 쓴 코드도 한 줄씩 읽고 의견을 남겨요. | 코드를 고치고 다시 실행해 보고 있을 거예요 · 평일 | 코드는 한 번에 보통 200~400줄씩 나눠 읽어요 (SmartBear 2006) |
| server-developer | 서버 개발자 · 민호 | 성남 판교 | 보낸 메시지와 주문을 받아 저장하고, 받을 사람에게 빠짐없이 건네는 프로그램을 만들어요. | 서버 기록을 살피고 있을 거예요 · 평일 | |
| qa-tester | QA 테스터 · 프엉* | 베트남 하노이 | 여러 휴대폰으로 같은 버튼을 수없이 눌러 보며, 고장 난 곳을 찾아 알려 줘요. | 휴대폰 여러 대를 번갈아 눌러 보고 있을 거예요 · 평일 | |
| localizer | 현지화 담당 · 소희 | 서울 | 앱 속 문장을 다른 나라 말로 옮기고, 화면에서 글자가 잘리지 않는지 확인해요. | 번역한 문장이 버튼에 들어가는지 보고 있을 거예요 · 평일 | (번역가 하루 2,000~3,000단어: 업계 경험칙이라 약함, 넣지 않는 쪽 추천) |
| app-reviewer | 앱 마켓 심사원 · 멜리사 | 미국 서니베일 | 새로 올라온 앱을 직접 써 보고, 약속한 규칙을 지키는지 확인해 통과시켜요. | 새로 올라온 앱을 눌러 보고 있을 거예요 · 평일 | |
| content-moderator | 신고 검수원 · 가은 | 강원 춘천 | 신고된 글과 사진을 살펴, 누군가를 다치게 하는 것이 없는지 가려내요. 모두가 편히 쓰도록 보이지 않는 곳을 지켜요. | 신고된 글을 하나씩 살피고 있을 거예요 | |

### 노래 만들기

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| track-maker | 트랙메이커 · 올레* | 노르웨이 트론헤임 | 건반과 컴퓨터로 코드와 박자를 쌓아 노래의 뼈대를 만들어요. 멀리 서울로 보낼 곡을 고르고 있어요. | 건반 앞에서 박자를 쌓고 있을 거예요 | |
| topliner | 탑라이너 · 유나 | 서울 | 비트를 들으며 흥얼흥얼 멜로디를 얹어요. 여러 나라 작곡가와 한 방에 모여 곡을 끝내기도 해요. | 비트를 틀어 놓고 흥얼거리고 있을 거예요 | 2주 송캠프에서 작곡가 45명이 약 55곡을 썼어요 (Warner Chappell Music Korea, 2022) |
| lyricist | 작사가 · 동훈 | 서울 | 데모 멜로디를 수없이 들으며 음절 수에 맞는 우리말을 찾아요. 부르기 쉬운 낱말을 고르고 또 골라요. | 데모를 반복해 들으며 가사를 고치고 있을 거예요 | |
| arranger | 편곡자 · 수연 | 서울 | 어떤 악기가 언제 들어올지 정해 노래의 흐름을 다듬어요. | 악기 소리를 하나씩 쌓아 보고 있을 거예요 | |
| session-player | 세션 연주자 · 경민 | 서울 | 기타나 현악기를 들고 녹음실에 와서, 처음 받은 악보를 그 자리에서 연주해요. | 녹음실에서 기타 줄을 고르고 있을 거예요 | |
| vocal-director | 보컬 디렉터 · 채원 | 서울 | 가수 옆에서 한 소절씩 감정과 발음을 함께 다듬고, 가장 좋은 목소리를 골라요. | 가수와 한 소절을 다시 불러 보고 있을 거예요 | |
| recording-engineer | 녹음 엔지니어 · 재석 | 서울 | 마이크를 세우고 소리를 깨끗하게 담아요. 숨소리 하나까지 들으며 녹음 버튼을 눌러요. | 헤드폰을 끼고 녹음 버튼을 누르고 있을 거예요 | |
| mixing-engineer | 믹싱 엔지니어 · 마이클 | 미국 버지니아비치 | 여러 갈래로 나뉜 소리의 크기와 자리를 맞춰 하나의 노래로 섞어요. | 소리 크기를 하나씩 맞추고 있을 거예요 | |
| mastering-engineer | 마스터링 엔지니어 · 리사 | 미국 뉴저지 | 다 섞인 노래가 어떤 이어폰으로 들어도 고르게 들리도록 마지막으로 다듬어요. | 여러 스피커로 같은 노래를 들어 보고 있을 거예요 | |
| album-designer | 앨범 아트 디자이너 · 은비 | 서울 | 노래의 분위기를 한 장의 그림으로 담아 앨범 표지를 만들어요. | 표지 색을 이리저리 바꿔 보고 있을 거예요 · 평일 | |
| music-distributor | 음원 유통 담당 · 상우 | 서울 | 발매 날짜와 시각을 정하고, 노래와 정보를 여러 음악 앱에 빠짐없이 올려요. | 발매할 노래의 정보를 맞추고 있을 거예요 · 평일 | 신곡은 보통 오후 6시에 나와요 (텐아시아 2018) |

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| datacenter-tech | 데이터센터 기술자 · 성우 | 경기 안산 | 서버가 가득한 방을 돌며 깜빡이는 불빛을 살펴요. 고장 난 부품은 그 자리에서 갈아 끼워요. | 서버실을 돌며 불빛을 살피고 있을 거예요 · 밤에도 교대 | |
| cable-repairer | 해저 케이블 수리선 선원 · 하린 | 바다 위 | 바다 밑 인터넷 선이 끊기면 배를 타고 나가 끌어올려요. 먼지 하나 없는 방에서 가는 유리 실을 한 가닥씩 이어요. | 갑판에서 바다를 살피고 있을 거예요 / 잠: 선실에서 자고 있을 거예요 | 얕은 바다에서는 약 1~3일이면 고쳐요 (USCC 제출 답변 2026) |
| base-station | 기지국 엔지니어 · 준기 | 서울 | 철탑에 올라 전파를 보내는 장비를 달고 방향을 맞춰요. 휴대폰이 잘 안 터지는 곳이 있으면 달려가요. | 철탑 위 장비의 방향을 맞추고 있을 거예요 · 평일 | 네 명이 약 33kg 장비를 밧줄로 25m 철탑 위까지 끌어올려요 (전자신문 2020) |

카드 문구는 해요체 현재진행형, 숫자·나라 이름 없음 규칙대로 썼어요.

## 넣을 때 같이 바꾸는 것

- 장소 새로: 성남 판교, 강원 춘천, 경기 안산, 베트남 하노이 시내, 노르웨이 트론헤임, 미국 서니베일 · 버지니아비치 · 뉴저지 에지워터.
- 이름: 미국 멜리사·마이클은 지금 미국 이름 출처(사회보장국 1970년대 순위)에서, 리사는 같은 출처에서 확인 후 확정. 베트남 린·프엉, 노르웨이 올레는 출처를 찾아 확인하고, 없으면 비워 두거나 정해 주는 이름으로.
- 걷기 화면: 앱·노래·인터넷 칸 사이는 "땅·하늘" 대신 "인터넷"으로 이어 쓰기를 제안해요(케이블 칸만 바다 점선). 나라를 건너는 칸 사이는 지금처럼 "약 7,000km" 거리만.
- 끝 가게 종류에 '앱'(고객센터 상담원)과 '없음'(노래)을 더해요.
- 일의 크기 숫자는 넣기 전에 원문을 다시 확인해요.
