# 게임 길 사람 카드 검토 표

피규어 대신 넣는 길이에요(2026-10 사용자 결정). 2026-10에 이 표대로 shared/data에 넣었어요.

## 물건과 길

| 물건 | 재료(길) | 끝 사람 |
|---|---|---|
| 게임 (게임, 모바일 게임, 온라인 게임, 롤플레잉 …) | ★게임 만들기 + 인터넷 | 없음 (인터넷 다음이 바로 '나') |

- 휴대폰·컴퓨터로 내려받아 하는 게임이라, 드라마·애니메이션처럼 인터넷 길(데이터센터 → 해저 케이블 → 기지국)을 지나 바로 "나"에게 와요.
- 한국 게임사들은 그래픽 일부를 베트남 하노이 같은 곳의 스튜디오에서 만들어 왔어요(머니투데이방송 2025: 2020년 하노이에 그래픽 전문 자회사, 다른 게임사들도 동남아에 그래픽 스튜디오). 그래서 3D 그래픽 칸을 하노이에 뒀어요.
- 출시 뒤에도 게임은 계속 바뀌어요. 마지막 칸은 업데이트와 이벤트를 여는 라이브 운영 담당이에요.
- 화면에는 게임·회사 이름을 쓰지 않아요.

**게임 만들기**: 게임 기획자 → 시나리오 작가 → 원화가 → 3D 그래픽 아티스트(하노이) → 애니메이터 → 이펙트 디자이너 → 레벨 디자이너 → 클라이언트 프로그래머 → 서버 프로그래머 → 사운드 디자이너 → QA 테스터 → 라이브 운영 담당 → (인터넷 길)

칸 사이 변신: 아이디어 → 기획서 → 세계와 대사 → 콘셉트 그림 → 3D 캐릭터 → 움직이는 캐릭터 → 반짝이는 효과 → 놀 수 있는 맵 → 화면 속 게임 → 함께 노는 서버 → 소리 든 게임 → 테스트 빌드 → 업데이트된 게임

## 사람 (새로 12명)

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| game-designer | 게임 기획자 · 지환 | 성남 판교 | 게임의 규칙과 목표, 레벨이 오르는 순서를 정해요. 어디서 즐거워하고 어디서 멈칫할지 먼저 상상해요. | 다음 업데이트의 규칙을 적고 있을 거예요 · 평일 | |
| game-writer | 게임 시나리오 작가 · 서진 | 성남 판교 | 게임 속 세계의 역사와 인물, 대사를 써요. 지나가는 마을 사람의 한마디까지 이 사람이 지어요. | 마을 사람의 대사를 쓰고 있을 거예요 · 평일 | |
| concept-artist | 원화가 · 하람 | 성남 판교 | 아직 아무도 본 적 없는 캐릭터와 장소를 처음으로 그려요. 이 그림을 보고 모두가 같은 세계를 떠올려요. | 새 캐릭터의 옷을 그려 보고 있을 거예요 · 평일 | |
| game-3d-artist | 3D 그래픽 아티스트 · 바오 | 베트남 하노이 | 원화를 보고 캐릭터와 건물을 입체로 빚고, 표면에 색과 무늬를 입혀요. | 캐릭터 갑옷의 무늬를 다듬고 있을 거예요 · 평일 | |
| game-animator | 애니메이터 · 수현 | 성남 판교 | 캐릭터가 달리고 뛰고 손을 흔드는 움직임을 하나씩 만들어요. 버튼을 누른 순간 바로 반응하게 다듬어요. | 달리기 동작을 여러 번 돌려 보고 있을 거예요 · 평일 | |
| vfx-designer | 이펙트 디자이너 · 은채 | 성남 판교 | 마법이 터지는 빛, 상자가 열릴 때 반짝이는 가루처럼 눈을 즐겁게 하는 효과를 만들어요. | 반짝이는 가루의 색을 맞추고 있을 거예요 · 평일 | |
| level-designer | 레벨 디자이너 · 도하 | 성남 판교 | 길과 장애물, 보물이 놓일 자리를 정해 맵을 짜요. 길을 잃지 않으면서도 구석구석 둘러보고 싶게 만들어요. | 맵 구석에 보물을 숨기고 있을 거예요 · 평일 | |
| client-programmer | 클라이언트 프로그래머 · 정우 | 성남 판교 | 그림과 규칙을 휴대폰과 컴퓨터에서 돌아가는 게임으로 엮어요. 버튼 하나가 눌리는 순간까지 코드로 짜요. | 버튼이 눌리는 순간을 코드로 고치고 있을 거예요 · 평일 | |
| server-programmer | 게임 서버 프로그래머 · 윤재 | 성남 판교 | 수많은 사람이 한 세계에서 같이 놀 수 있게, 모두의 움직임을 받아 맞추는 서버를 만들어요. | 서버 기록을 살피고 있을 거예요 · 평일 | |
| sound-designer | 사운드 디자이너 · 아린 | 서울 | 칼이 부딪히는 소리, 레벨이 오를 때의 짧은 음악처럼 게임 속 소리를 만들어요. | 레벨이 오를 때 날 소리를 고르고 있을 거예요 · 평일 | |
| game-qa | 게임 QA 테스터 · 세린 | 성남 판교 | 같은 길을 수없이 걸어 보고, 벽에 끼거나 멈추는 곳을 찾아 알려 줘요. | 같은 퀘스트를 다시 해 보고 있을 거예요 · 평일 | |
| live-ops | 라이브 운영 담당 · 가람 | 성남 판교 | 출시한 뒤에도 매주 새 이벤트를 열고 공지를 띄워요. 점검 날에는 모두가 다시 들어올 때까지 지켜봐요. | 다음 이벤트 공지를 쓰고 있을 거예요 / 저녁: 점검이 끝난 서버를 지켜보고 있을 거예요 | |

카드 문구는 해요체 현재진행형, 숫자·나라 이름 없음 규칙대로 썼어요. 일의 크기 숫자는 출처를 찾지 못해 이번 길에는 없어요.

## 넣을 때 같이 바꾸는 것

- 장소는 지금 있는 판교·서울·하노이를 써요.
- 걷기 칸 사이는 드라마·애니메이션처럼 "인터넷".
- 마을(지금 쓰지 않는 화면)은 자리가 남은 언덕 구역에 두어 검사를 그대로 지켜요.
