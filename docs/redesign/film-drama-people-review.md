# 영화·드라마 길 사람 카드 검토 표

new-paths-draft.md "1. 한국 영화", "2. K-드라마"를 데이터로 옮긴 표예요. 2026-10에 이 표대로 shared/data에 넣었어요.
일의 크기 숫자는 원문을 확인하지 못해 아직 넣지 않았어요. 마을(지금 쓰지 않는 화면)의 '우리 집' 자리가 모자라 촬영장 사람은 언덕, 후반 작업실 사람은 항구 구역에 두었어요.

## 물건과 길

| 물건 | 재료(길) | 끝 사람 |
|---|---|---|
| 영화 (영화, 영화관, 극장 …) | ★영화 만들기 | ★극장 영사 담당 (새 가게 종류 '극장') |
| 드라마 (드라마, 시리즈, 넷플릭스 …) | ★드라마 만들기 + 인터넷(지금 있는 길) | 없음 (노래처럼 인터넷 다음이 바로 '나') |

- 영화는 극장에서 보는 길, 드라마는 휴대폰·TV 앱으로 보는 길로 나눴어요. 드라마가 지나는 인터넷 길(데이터센터 → 해저 케이블 → 기지국)은 앱·노래와 같은 사람들이에요.
- 해외로 나가는 칸(다른 나라 말 자막·더빙)은 우리 화면에 닿는 길이 아니라 넣지 않았어요.
- 로케이션 매니저·VFX 아티스트·사운드 믹싱 엔지니어는 영화와 드라마에 같이 나오는 한 사람씩이에요(배·물류센터 사람처럼 여러 길에 서요).
- 화면에는 작품·회사·서비스 이름을 쓰지 않아요. "넷플릭스"로 입력해도 화면에는 "드라마"로.

**영화 만들기**: 시나리오 작가 → 로케이션 매니저 → 세트 제작 미술팀(전주) → 의상 담당 → 붐 오퍼레이터 → 조명 기사 → 편집감독 → VFX 아티스트 → 컬러리스트 → 폴리 아티스트 → 사운드 믹싱 엔지니어 → 배급 담당 → (끝) 극장 영사 담당
**드라마 만들기**: 극본 작가 → 편성 담당 → 로케이션 매니저 → 스튜디오 세트 제작자(대전) → 촬영 감독 → DIT → 드라마 편집자 → VFX 아티스트 → 음악감독 → 사운드 믹싱 엔지니어 → 인코딩 엔지니어 → (인터넷 길)

칸 사이 변신:
- 영화: 아이디어 → 시나리오 → 촬영 장소 목록 → 세트 → 현장 소리 → 촬영 원본 → 편집본 → 합성본 → 색보정본 → 효과음 든 영상 → 완성본 → 상영 파일
- 드라마: 아이디어 → 회차별 대본 → 편성이 정해진 대본 → 촬영 장소 목록 → 세트 → 촬영 원본 → 정리된 촬영 데이터 → 회차 편집본 → 합성본 → 음악 든 영상 → 회차 완성본 → 스트리밍 파일

## 사람 (새로 21명)

### 영화와 드라마에 같이 나오는 사람

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| location-manager | 로케이션 매니저 · 나연 | 전국 | 대본 속 장소를 찾아 전국을 달려요. 마음에 드는 곳을 찾으면 주인을 찾아가 촬영을 부탁해요. | 촬영할 장소를 찾아 운전하고 있을 거예요 | 촬영지를 찾아 두 달에 약 3만 km를 달린 적이 있어요 (TV리포트) |
| vfx-artist | VFX 아티스트 · 민혁 | 서울 | 화면에 없던 우주선이나 눈보라를 컴퓨터로 그려 넣고, 필요 없는 것은 감쪽같이 지워요. | 한 장면씩 그래픽을 합성하고 있을 거예요 · 평일 | |
| sound-mixer | 사운드 믹싱 엔지니어 · 인호 | 서울 | 대사와 효과음, 음악의 크기와 자리를 섞어 하나의 소리로 만들어요. | 큰 스피커 앞에서 소리 크기를 맞추고 있을 거예요 · 평일 | |

### 영화만

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| screenwriter | 시나리오 작가 · 진수 | 서울 | 감독과 마주 앉아 인물과 장면, 대사를 글로 짜요. 영화는 이 사람의 빈 종이에서 처음 시작돼요. | 장면 하나를 고쳐 쓰고 있을 거예요 / 저녁: 극장에서 다른 영화를 보고 있을 거예요 | |

| boom-operator | 붐 오퍼레이터 · 보영 | 촬영 현장 | 긴 장대 끝에 마이크를 달고 화면 바로 바깥에서 배우의 목소리를 받아요. 팔을 든 채 숨죽여 버텨요. | 마이크 장대를 들고 숨죽이고 있을 거예요 | |
| gaffer | 조명 기사 · 정민 | 촬영 현장 | 장면마다 빛의 방향과 세기를 맞춰요. 해 질 녘 같은 빛을 한밤에도 만들어 내요. | 조명 각도를 맞추고 있을 거예요 | |
| film-editor | 편집감독 · 서희 | 서울 | 찍어 온 장면 가운데 쓸 것을 골라 순서와 길이를 정해요. 같은 장면을 수없이 돌려 봐요. | 같은 장면을 앞뒤로 돌려 보고 있을 거예요 · 평일 | |
| colorist | 컬러리스트 · 도경 | 서울 | 장면마다 색과 밝기를 맞춰 영화 전체의 분위기를 정해요. | 어두운 방에서 화면 색을 맞추고 있을 거예요 · 평일 | |
| foley-artist | 폴리 아티스트 · 준석 | 서울 | 화면에 맞춰 발소리, 문 닫는 소리 같은 작은 소리를 직접 내요. 사탕을 깨물고 캔을 따기도 해요. | 녹음실에서 발소리를 내고 있을 거예요 · 평일 | (사탕 먹는 소리 하나에 사탕 두 통: 원문 확인 후) |
| film-distributor | 배급 담당 · 다혜 | 서울 | 언제 어느 극장에서 영화를 걸지 정하고, 상영할 파일을 극장마다 보내요. | 극장마다 보낼 상영 일정을 맞추고 있을 거예요 · 평일 | |
| projectionist | 극장 영사 담당 · 세영 | 우리 동네 | 상영 파일을 극장 서버에 올리고, 불이 꺼지기 전에 화면과 소리를 마지막으로 살펴요. 오늘 이 영화를 틀어 준 사람이에요. | 다음 상영 화면을 살피고 있을 거예요 / 저녁: 마지막 회차 영화를 틀고 있을 거예요 | |

### 드라마만

| id | 일 · 이름 | 장소 | 카드 문구 | 지금은 아마 | 일의 크기 후보 |
|---|---|---|---|---|---|
| drama-writer | 극본 작가 · 규리 | 서울 | 회마다 다음 이야기가 궁금하도록 대본을 써요. 방송이 시작된 뒤에도 다음 회를 고쳐 쓰기도 해요. | 다음 회 대본을 쓰고 있을 거예요 | |
| scheduler | 편성 담당 · 한별 | 서울 | 어떤 드라마를 언제, 어느 채널이나 앱에 내보낼지 정해요. | 다음 계절 편성표를 맞추고 있을 거예요 · 평일 | 편성이 나면 보통 한두 달 안에 배우와 촬영지를 정해요 (원문 확인 후) |
| studio-set-builder | 스튜디오 세트 제작자 · 태윤 | 대전 | 넓은 스튜디오 안에 드라마 속 집과 거리를 지어요. 회차가 끝날 때까지 몇 번이고 고쳐 써요. | 세트 문짝을 다시 달고 있을 거예요 | |
| cinematographer | 촬영 감독 · 경태 | 촬영 현장 | 카메라 자리를 정하고, 배우의 표정이 가장 잘 보이는 각도를 찾아요. | 카메라 자리를 옮겨 보고 있을 거예요 | |
| dit | DIT(촬영 데이터 관리자) · 은솔 | 촬영 현장 | 하루 동안 찍은 영상 파일을 받아 여러 번 백업하고, 빠진 장면이 없는지 확인해요. | 오늘 찍은 파일을 옮겨 담고 있을 거예요 | |
| drama-editor | 드라마 편집자 · 재훈 | 서울 | 회마다 끝나는 지점을 정해, 다음 회가 궁금해지게 이어 붙여요. | 이번 회 마지막 장면을 고르고 있을 거예요 | |
| music-director | 음악감독 · 소영 | 서울 | 인물마다 어울리는 노래를 만들고, 드라마 속 모든 배경 음악을 맡아요. | 인물 테마를 피아노로 쳐 보고 있을 거예요 | 방송 약 4~5개월 전부터 곡을 써요 (OSEN, 원문 확인 후) |
| encoding-engineer | 인코딩 엔지니어 · 혜린 | 서울 | 완성된 영상을 잘게 나눠 화질별로 압축해요. 어떤 휴대폰에서도 끊기지 않게 보이도록요. | 압축이 끝난 영상을 돌려 보고 있을 거예요 · 평일 | |

카드 문구는 해요체 현재진행형, 숫자·나라 이름 없음 규칙대로 썼어요. 고된 노동을 드러내는 사실(근로시간, 밤샘, 건강 문제)은 조사에 나왔지만 넣지 않았어요.

## 넣을 때 같이 바꾸는 것

- 장소 새로: 전주, 대전. '촬영 현장'·'전국'은 지금 있는 '대한민국' 장소를 써요.
- 끝 가게 종류에 '극장'(극장 영사 담당)을 더하고, 드라마는 노래처럼 '없음'.
- 걷기: 만드는 칸 사이는 지금 규칙(같은 나라 안은 땅, 가까우면 적지 않음)이라 대부분 아무것도 적히지 않아요. 드라마가 지나는 인터넷 길만 앱·노래처럼 "인터넷".
- 일의 크기 숫자는 원문을 확인하지 못하면 넣지 않아요.
