# 해외 사무실 칸 검토 표

people-on-path.md "정한 것" 1번(물건 길에 해외 사무실 칸)을 데이터로 옮긴 표예요. 2026-10에 이 표대로 shared/data에 넣었어요.
길 위 사람 수가 늘어 예전 기능(하루 유형 테스트·실타래)의 예시 숫자를 고쳤고, 마을(지금 쓰지 않는 화면)은 자리가 넘치면 빈 땅에 서도록 검사를 풀었어요.

물건은 원산지에서도 농장·공장과 항구 사이에 사무실을 거쳐요: 맛을 보고 등급을 매기는 사람, 수출 서류를 맞추는 사람, 배 자리를 잡는 사람, 주문과 공장 사이를 잇는 사람.
지금 길에는 브라질·베트남 커피 수출 담당 둘뿐이라, 원산지마다 한 칸씩 더해요. 나중에 해외 사무직 사용자가 설 자리이기도 해요.

## 들어갈 자리

| 길 | 지금 | 바뀐 뒤 (★ 새 칸) |
|---|---|---|
| 커피 · 에티오피아 | 수확자 → 워싱 스테이션 → 지부티 항구 | 수확자 → 워싱 스테이션 → ★커피 맛 감정사(아디스아바바) → 지부티 항구 |
| 커피 · 콜롬비아 | 농부 → 부에나벤투라 항구 | 농부 → ★커피 수출 서류 담당(보고타) → 부에나벤투라 항구 |
| 카카오 · 코트디부아르 | 농부 → 발효·건조 → 아비장 항구 | 농부 → 발효·건조 → ★카카오 수출 회사 선적 담당(아비장) → 아비장 항구 |
| 카카오 · 가나 | 농부 → 타코라디 항구 | 농부 → ★카카오 수매 담당(가나 서부 주) → 타코라디 항구 |
| 바나나 · 필리핀 | 포장 작업자 → 다바오 항구 | 포장 작업자 → ★선적 일정 담당(다바오) → 다바오 항구 |
| 면 · 방글라데시 | 봉제 공장 → 치타공 항구 | 봉제 공장 → ★의류 머천다이저(다카) → 치타공 항구 |
| 기기 조립 · 베트남 | 공장 → 하노이 공항 | 공장 → ★운송 주선 업체 직원(하노이) → 하노이 공항 |
| 연어 · 노르웨이 | 가공장 → 오슬로 공항 | 가공장 → ★수산물 수출 영업 담당(노르웨이 피오르) → 오슬로 공항 |
| 소고기 · 호주 | 가공장 → 배 | 가공장 → ★수출 검역 서류 담당(퀸즐랜드) → 배 |
| 콩 · 브라질 | 농부 → 산투스 항구 | 농부 → ★곡물 수출 회사 직원(상파울루주) → 산투스 항구 |
| 고추 · 중국 | 분쇄 공장 → 칭다오 항구 | 분쇄 공장 → ★무역 회사 직원(칭다오) → 칭다오 항구 |

- 사무실 칸에서는 물건 모습이 바뀌지 않아요(칸 사이 변신 없음). 커피 맛 감정사처럼 등급을 매기는 칸도 생두는 그대로예요.
- 지금 있는 퀴즈 보상 카드(카카오 품질 검사원·곡물 무역 트레이더)와 겹치지 않게 일을 골랐어요.
- 가나 수매 담당은 농가에서 카카오 콩을 사들이는 일이에요(가나는 정부 기관이 정한 값으로 허가받은 회사가 사들여요).

## 넣을 때 같이 바꾸는 것

- 장소 새로: 콜롬비아 보고타, 필리핀 다바오 시내(지금 '다바오 항구'를 써도 됨), 중국 칭다오 시내(지금 '칭다오 항구'를 써도 됨). 나머지는 지금 있는 장소.
- 커피·카카오는 출발지 변형(origins)의 칸 수가 하나씩 늘어요. 예전 여정 기록은 사람 id로 남아 있어서 영향이 없어요.
- 형태(forms.ts)는 바뀌지 않아요. 사무실 칸은 by가 없어요.
- 마을(지금 쓰지 않는 화면)은 자리가 넘치면 빈 땅에 서요.
