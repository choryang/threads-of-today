# 새 길 초안: 서비스·콘텐츠·컴퓨터 (검토용)

people-on-path.md의 "닿은 서비스"와 사용자 요청(영화·드라마 구분, 책, 피규어, 애니메이션 한국·일본, 키보드·마우스·모니터·컴퓨터, 앱·노래)을 조사해 길로 짠 초안이에요.
아직 데이터(shared/data)에 넣지 않았어요. 검토해서 고른 것만 사람 카드·재료·형태·일의 크기로 옮겨요.

## 먼저 알아 둘 것

- 조사 환경에서 기사 원문을 열 수 없어서, 사실은 모두 검색 결과의 발췌로만 확인했어요. 데이터에 넣기 전에 숫자마다 출처 원문을 한 번 열어 확인해요.
- 화면에는 회사·작품·서비스 이름을 쓰지 않아요(자료에 나온 이름은 출처 확인용). 장소는 도시·나라까지만.
- 일의 크기는 원칙 11대로 한 사람의 하루·한 개 단위 숫자를 먼저 골랐어요. 공장 전체 숫자는 빼거나 마지막 후보로만.
- 고된 노동을 드러내는 숫자(근로시간, 밤샘, 건강 문제)는 넣지 않아요. 조사에서 나왔지만 일부러 뺐어요.
- 출처가 약한 해외 칸("~로 알려졌다" 한 곳뿐)은 한국으로 두거나 칸을 빼요.

표의 "형태"는 걷기의 칸 사이 변신(forms.ts)에 쓰고, "일의 크기"는 workFact 후보예요. 비어 있으면 숫자 없이 갑니다.

## 공통 칸: 스트리밍·인터넷

영화·드라마·앱·노래가 같이 지나요. 걷기에서는 거리 대신 "인터넷"으로 잇고, 해저 케이블 칸만 바다 점선.
- 인코딩 엔지니어: 완성본을 잘게 잘라 화질 단계별로 압축해요.
- 데이터센터 기술자: 부산·안산·세종.
- 캐시 서버 담당: 많이 볼 작품을 새벽에 동네 가까운 서버에 미리 채워 둬요. 새 서버는 이틀쯤 채워요(Open Connect 문서).
- 해저 케이블 수리선 선원: 부산. 나라 사이 통신은 거의 전부 바다 밑 광케이블로 오가요. 얕은 바다는 무인 잠수정으로 1~3일, 깊은 바다는 일주일 넘게 걸려요(USCC 2026). 끌어올린 케이블은 먼지 없는 선상 방에서 한 가닥씩 이어요.
- 기지국 엔지니어(앱 길과 같은 칸).

1. 이 길들 가운데 무엇부터 넣을지. 추천 순서: 책(지금 종이 길과 바로 이어짐) → 키보드·마우스·모니터·컴퓨터(지금 반도체·플라스틱 길 재사용) → 노래·앱(공통 칸 포함) → 영화·드라마 → 애니메이션 두 길 → 피규어.
