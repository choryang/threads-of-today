# 애니메이션 길 사람 카드 검토 표

new-paths-draft.md "3. 일본 TV 애니메이션", "4. 한국 3D 유아 애니메이션"을 데이터로 옮기기 전 초안이에요. 고칠 문구·이름을 알려 주면 그대로 반영해서 넣어요.

## 물건과 길

| 물건 | 재료(길) | 끝 사람 |
|---|---|---|
| 애니메이션 (애니메이션, 애니, 일본 애니 …) | ★일본 TV 애니메이션 + 인터넷 | 없음 (인터넷 다음이 바로 '나') |
| 어린이 애니메이션 (어린이 애니메이션, 유아 애니, 만화영화 …) | ★한국 3D 애니메이션 + 인터넷 | 없음 |

- 둘 다 휴대폰·TV 앱으로 보는 길이라 드라마처럼 인터넷 길(데이터센터 → 해저 케이블 → 기지국)을 지나 바로 "나"에게 와요.
- 일본 길은 가운데 칸이 나라를 건너요: 원화는 도쿄에서 그리고, 동화는 서울, 채색은 마닐라에서 한 뒤 다시 도쿄로 돌아가 합쳐요(일본 공정거래위원회 실태조사 2025: 동화·채색을 한국·필리핀 등에 맡겨 왔어요). 한국이 이 일을 받기 시작한 것은 1960년대 후반이에요.
- 한국 3D 길은 그리는 대신 한 번 만든 모델을 움직이고, 마지막 그림은 컴퓨터가 계산해요. 그래서 동화·채색 대신 모델링·리깅·라이팅·렌더링 칸이 있어요.
- 해외 판매·각국 더빙 칸은 우리 화면에 닿는 길이 아니라 넣지 않았어요(영화·드라마와 같은 기준).
- 화면에는 작품·회사·서비스 이름을 쓰지 않아요.

**일본 TV 애니메이션**: 기획 프로듀서 → 각본가 → 그림 콘티 연출 → 원화가 → 작화 감독 → 동화가(서울) → 동화 검사 → 채색 담당(마닐라) → 배경 미술 → 촬영 감독(합성) → 성우 → 음향 감독 → 한국어 자막 번역가(서울) → (인터넷 길)
**한국 3D 애니메이션**: 기획 PD → 시나리오 작가 → 캐릭터 디자이너 → 스토리보드 작가 → 3D 모델러 → 리거 → 3D 애니메이터 → 라이팅 아티스트 → 렌더팜 관리자 → 컴포지터 → 더빙 성우 → 음악·음향 담당 → (인터넷 길)

칸 사이 변신:
- 일본: 원작 → 기획서 → 각본 → 그림 콘티 → 원화 → 고친 원화 → 동화 → 검사 마친 동화 → 칠한 그림 → 배경 → 촬영된 컷 → 목소리 든 영상 → 완성 에피소드 → 한국어 자막판
- 한국: 아이디어 → 기획서 → 시나리오 → 캐릭터 설정화 → 스토리보드 → 3D 모델 → 움직일 수 있는 모델 → 움직임 → 조명 든 장면 → 그림 한 장 한 장 → 완성 영상 → 목소리 든 영상 → 완성 에피소드

## 사람 (새로 25명)

이름은 출처 없이도 그 나라의 평범한 이름으로 붙였어요.

카드 문구는 해요체 현재진행형, 숫자·나라 이름 없음 규칙대로 썼어요. 조사에 나온 고된 노동 이야기(일의 양, 밤샘)는 넣지 않았어요.

## 넣을 때 같이 바꾸는 것

- 장소 새로: 일본 도쿄, 필리핀 마닐라. 일본은 처음 들어오는 나라라 공휴일 데이터를 새로 만들어요.
- 물건 이름: 애니메이션·애니·일본 애니 → 일본 길, 어린이 애니메이션·유아 애니·만화영화 → 한국 길.
- 일의 크기 숫자는 원문을 확인하지 못하면 넣지 않아요.
