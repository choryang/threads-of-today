# 책 길 사람 카드 검토 표

new-paths-draft.md "5. 책"을 데이터로 옮긴 표예요. 2026-10에 이 표 그대로 shared/data에 넣었어요.
제본 작업자의 일의 크기(320쪽 = 10묶음)는 원문을 확인하지 못해 아직 넣지 않았어요.

## 길

- 새 재료 "출판"(publishing). 책 = 출판 + 종이(지금 있는 종이 길: 유칼립투스 → 펄프 → 산투스항 → 벌크선 → 제지 공장 → 물류센터).
- 출판이 첫 재료라서, '오늘'에서 책을 고르면 이 길의 사람 가운데 한 명을 만나요.
- 출판 길: 작가 → (번역서면 번역가) → 편집자 → 교정·교열자 → 북디자이너 → 조판 디자이너 → 인쇄 기장 → 제본 작업자 → 출판 물류센터 직원.
- 끝 사람: 서점 직원(새 가게 종류 '서점'), 또는 지금 있는 택배 기사(온라인 주문).
- 번역가는 출발지 변형으로: 걸을 때마다 가끔 번역서 길이 나와요.
- 칸 사이 변신: 원고 → 다듬은 원고 → 교정지 → 인쇄용 파일 → 인쇄된 종이 → 책.

이름은 지금 쓰지 않는 이름에서 골랐어요. 장소 '파주'는 새로 추가(파주출판도시에 출판·인쇄·제본·물류가 모여 있어요, 경기일보 2025 · 프레시안).

## 바꾸는 것

- 물건 이름 매칭: '책', '소설', '만화책', '잡지', '교과서', '문제집' → 출판 + 종이. 지금은 '책'이 종이 길만 가요.
- 끝 가게 종류에 '서점'을 더해요(이름에 책·소설 등이 있으면 서점 직원).
- 모든 문구는 해요체 현재진행형, 숫자·나라 이름 없음(check:data).
