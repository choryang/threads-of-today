# 컴퓨터·주변기기 길 사람 카드 검토 표

new-paths-draft.md "7. 컴퓨터와 주변기기"를 데이터로 옮기기 전 초안이에요. 고칠 문구·이름을 알려 주면 그대로 반영해서 넣어요.

## 물건과 길

| 물건 | 재료(길) | 끝 사람 |
|---|---|---|
| 키보드 | ★기계식 스위치, ★회로기판, 플라스틱 | 택배 기사 (온라인 주문, 지금 있는 '물건' 끝) |
| 마우스 | ★광센서, ★회로기판, 플라스틱 | 택배 기사 |
| 모니터 | ★디스플레이 패널, ★회로기판, 플라스틱 | 택배 기사 |
| 컴퓨터(데스크톱) | ★CPU, ★메모리, ★회로기판, 반도체, 알루미늄, 플라스틱 | ★용산 조립 PC 기사 (새 가게 종류 '컴퓨터') |

★는 새 길이에요. 새 길 여섯 개는 아래와 같아요. 굵은 글씨가 새 사람이고, 나머지는 지금 있는 사람을 다시 써요.

- **기계식 스위치**: **스위치 공장 작업자**(둥관) → **스위치 검사원**(둥관) → **키보드 조립원**(주하이) → 컨테이너선 선원 → 부산항 크레인 기사 → 물류센터 작업자
- **회로기판**: **구리 광산 트럭 운전사**(칠레 에스콘디다) → 벌크선 선원 → **구리 제련 기술자**(울산 온산) → **동박적층판 기술자**(충북 증평) → **회로기판 공장 기술자**(중국) → **부품 장착(SMT) 기사**(대만 타오위안) → 항공화물 조업원
- **디스플레이 패널**: **유리 기판 기술자**(중국 허페이) → **패널 공정 엔지니어**(파주) → **모듈 조립원**(베트남 하이퐁) → **모니터 조립원**(호찌민) → 컨테이너선 선원 → 부산항 크레인 기사 → 물류센터 작업자
- **CPU**: **CPU 팹 엔지니어**(대만 타이난) → 반도체 후공정 작업자(페낭, 지금 사람) → 항공화물 조업원 → 물류센터 작업자
- **메모리**: 클린룸 엔지니어(경기도, 지금 사람) → **메모리 패키징 기술자**(아산 온양) → 물류센터 작업자
- **광센서**: **센서 칩 설계자**(대만 신주) → **마우스 조립원**(중국 쑤저우) → 컨테이너선 선원 → 부산항 크레인 기사 → 물류센터 작업자

칸 사이 변신:
- 기계식 스위치: 플라스틱 알갱이 → 스위치 → 검사 마친 스위치 → 키보드
- 회로기판: 구리 광석 → 구리판 → 동박적층판 → 빈 회로기판 → 부품 붙은 기판
- 패널: 유리 기판 → 패널 → 디스플레이 모듈 → 모니터
- CPU: 웨이퍼 → 회로 새긴 웨이퍼 → CPU
- 메모리: 웨이퍼 → 회로 새긴 웨이퍼 → 메모리 칩
- 광센서: 센서 칩 → 마우스

쓰지 않은 칸(장소 출처가 없어서): 동박 공장, 편광판, 백라이트, 키캡 공장, 메모리 모듈 공장. 스위치는 독일에서 만든다고 쓰지 않아요(2025년에 생산을 옮겼어요).

## 사람 (새로 17명)

이름 옆 *는 출처 있는 이름 목록에서 아직 확인하지 못한 후보예요. 넣을 때 그 나라 이름 순위 출처를 찾아 확인하고, 없으면 다른 이름으로 바꾸거나 비워 둬요(지금 규칙 그대로).

카드 문구는 해요체 현재진행형, 숫자·나라 이름 없음 규칙대로 썼어요.

## 넣을 때 같이 바꾸는 것

- 장소 새로: 중국 둥관 · 주하이 · 허페이 · 쑤저우, 칠레 에스콘디다, 충북 증평, 울산 온산(지금 '울산'을 써도 됨), 대만 타오위안 · 타이난 · 신주, 베트남 하이퐁, 호찌민 하이테크파크, 아산 온양, 서울 용산.
- 대만은 처음 들어오는 나라라 공휴일 데이터(npm run holidays)와 이름 묶음(출처 포함)을 새로 만들어요.
- 물건 이름: 키보드·기계식 키보드, 마우스, 모니터, 컴퓨터·데스크톱·본체. 지금 '컴퓨터'는 반도체 재료로 가는데, 새 물건으로 옮겨요(노트북은 그대로).
- 일의 크기 숫자는 넣기 전에 원문을 다시 확인해요. 확인 못 하면 빼요.
- 중국 이름: 지금 출처(공안부 이름 보고 등)에 나온 이름은 이미 다 쓰고 있어서, 중국 사람 여섯 명은 새 출처를 찾아 이름을 정해요.
- 한국 이름: 출처 있는 이름 목록에서 남은 이름이 거의 없어요(지우·윤서·예준만 남음). 서준·하준은 2015년 상위 이름이라 지금 일하는 나이와 맞지 않아요. 넣을 때 1980~90년대 이름 순위 출처를 하나 더 찾아 그 목록에서 고를게요.
