# 위차이 연재: 사실 메모 (초안, 검토용)

- 사람: tanker-crew (위차이 · 탱커선 선원), 장소 sea (바다 위). 국적은 정하지 않는다.
- 목적: 지금 10편(2시즌 '실수와 책임' · '물려주는 말')을 450~550자 연재로 늘리기 전에, 배경 중 무엇이 사실이고 무엇을 지어낼지 정한다. 원고는 [tanker-crew-serial.md](tanker-crew-serial.md).

## 1. 이야기에 쓸 실제 배경

| 사실 | 이야기에 쓰는 법 | 출처 |
|---|---|---|
| 탱커선은 펌프와 관·밸브로 액체 화물을 탱크에 싣고 내린다. 하역 중에는 펌프·밸브를 점검하는 당직이 있고, 밸브 정렬이 중요한 일이다 | 1화 펌프실에서 표식과 손잡이 방향 맞추기, 6~7화 하역 중 쉴 틈 없는 기관실 | 위키백과 Pumpman, 구인 글(Martide, OSM Thome), LiveSeas. **출처가 약하다**(위키·구인·직무 소개 글) |
| 기관실 순찰은 압력·온도·눈금을 읽어 일지에 적고, 새는 곳·이상한 소리·진동·과열을 찾는 일이다. 이상은 기관 일지에 적고 기관장에게 알린다 | 1화 소리를 적는 수첩, 2화 끊겼다 이어지는 쇳소리, 4화 기관 일지의 한 줄, 10화 막내와의 순찰 | STCW 기반 순찰 평가 항목(Mass. Maritime), 기관장 상시 지시서(TDI-BI). 교육 자료라 규정 원문은 아니다 |
| 밤에는 기관실을 비워 두는 무인 운전(UMS)을 하고, 이상이 생기면 경보가 기관실과 당번 기관사 선실에 울려 기관사가 내려간다. 무인 운전 전에 당번이 꼼꼼히 순찰한다 | 3화 한밤중 경보, 작업복을 꿰고 뛰어 내려가는 사람들 | Marine Insight, Maritime Page, SAFETY4SEA |
| 기관사(당직 기관사) 자격은 정해진 승선 경력과 교육을 채우고 시험을 봐야 받는다. 영국 등은 시험관과 마주 앉는 구술시험을 본다. 조건은 나라마다 다르다 | 1화 근무 뒤 두꺼운 책, 2화 다음 시험까지 배를 한참 더 타야 한다, 5화 말로 묻고 답하는 시험 | AMSA Engineer Watchkeeper, 영국 MCA 안내(MIN 468, MSF 4275) |
| 바다 위 연락은 위성 인터넷이라 느리고 끊기며, 항구 앞·육지 가까이에서야 휴대폰 신호가 잡힌다 | 2화 신호가 잡히는 짧은 틈의 엄마 전화, 9~10화 짧은 메시지 | SEAFiT 2024, Nautilus |
| IMO는 지친 선원에게 배를 계속 맡기는 것이 안전 위험이라고 경고했다 | 7화 짧게 쪼개 자는 잠과 "나중에" (피로를 탓하지 않고 배경으로만) | Marine Link(IMO 발표) |

## 2. 조심할 것

- **위차이의 자리를 정했다**: 1시즌은 기관실 선원(기관사를 돕는 부원)으로 펌프실·기관실 순찰을 돌고, 2시즌은 기관사. 실제 배에서 펌프실 밸브는 갑판부(펌프맨·일등항해사)가 맡는 경우가 많다. 이야기에서는 기관실 선원이 순찰 중 펌프실 밸브를 짚는 것으로 두었다(지어낸 부분). 걸리면 1화 첫 문단을 "기관실의 연료·냉각수 밸브"로 바꿀 수 있다.
- **특정 사고(탱커 화재·폭발·기름 유출)는 쓰지 않는다.** 3화 경보, 7화 기관이 멈춘 일은 다치는 사람·새는 화물 없이 끝낸다.
- **화물 이름(원유 등)과 국적을 쓰지 않는다.** 독자와는 "당신의 물건 속 재료", "당신에게 닿은 물건"으로 잇는다.
- **시험의 승선 기간·합격 기준 같은 숫자는 쓰지 않는다.**
- **실수를 벌하는 이야기로 쓰지 않는다.** 경위서는 책임지는 사람의 밤으로, 막내는 배우는 사람으로 쓴다.

## 3. 지금 10편과의 관계

지금 10편의 사건과 순서를 그대로 뼈대로 썼다(1화 = 1편 … 10화 = 10편). 바꾼 사건은 없다.
더한 것: 2화 끝에 적고 지나친 쇳소리(3~4화의 실마리), 선배의 질문 "뭐 적은 거 있어?", 5화 구술시험에서 그날 밤 이야기를 하는 장면, 6화 막내에게 건넨 새 수첩, 8화 문틈의 쪽지, 10화 선배의 고백 "나도 너한테 나중에, 소리 많이 했어".
지금 4편의 "위차이가 낮에 이상한 소리를 수첩에 적어 둬서"는 2화에 미리 심었다. 지금 9편의 "후배의 새 수첩 한 장"은 6화에 건넨 새 수첩의 첫 장으로 이었다.
joy "수첩에 적어 둔 작은 소리 하나"는 2·4·9·10화에 걸쳐 쓴다.
