# 민서 연재: 사실 메모 (초안, 검토용)

- 사람: mart-cashier (민서 · 동네 마트 계산원), 장소 kr-town
- 여러 여정에 나오는 사람(가게)이라 독자와 잇는 문장에 재료·물건 이름을 쓰지 않는다("당신의 물건"). 장바구니 속 물건(두부·대파·귤)은 민서가 보는 손님의 장보기라 썼다(정한 것 5번).
- 지금 stories.ts의 민서 10편·2시즌과 joy는 건드리지 않았다. 원고는 [mart-cashier-serial.md](mart-cashier-serial.md).

## 1. 이야기에 쓸 실제 배경

| 사실 | 이야기에 쓰는 법 | 출처 |
|---|---|---|
| 대형마트들이 셀프 계산대를 해마다 늘렸고, 한 지역에서는 몇 해 사이 몇 대에서 수십 대로 늘었다. 계산대 가운데 셀프 계산대가 더 많은 매장도 있다 | 1화 끝 바닥에 줄자를 대는 사람들, 2화 "계산대 몇 개는 없어진다". 숫자는 쓰지 않는다 | 매일신문(2022) |
| 셀프 계산대가 늘며 유인 계산대 인력이 줄었다는 노조 주장이 있고, 업계는 계산원을 다른 업무에 배치할 수 있다고 설명한다. 갑작스러운 다른 업무 발령을 퇴사 압박으로 받아들이는 계산원도 있다 | 2화 면담 "밤 근무로 옮기거나, 다른 지점으로 가거나"(지금 2편), 떠나는 정숙 언니 | 시대 보도, 데일리안·다음 뉴스(노조 주장 포함이라 한쪽 입장) |
| 고령 손님은 셀프 계산대를 잘 쓰지 않아 줄이 길어도 유인 계산대로 가고, 유인 계산대가 줄면 기다림이 길어져 계산원이 손님 불만까지 받게 된다는 지적이 있다 | 3화 길어진 줄, 기계 앞에서 한참 서 있는 할머니, 뒤의 한숨 | 매일신문(2022), getcha 커뮤니티에 옮겨진 기사(원문 확인 못 함) |
| 매장마다 손님 연령에 따라 셀프 계산대 비율을 달리 운영하고, 고령 손님이 많은 곳은 유인 계산대를 남긴다 | 6화 "다른 지점에도 할머니 같은 손님이 있을 것", 9화 할머니의 새 동네 지점 | 매일신문(2022), 시대 보도 |

| 셀프 계산대 화면은 바코드를 찍게 안내하고, 봉투 구매·결제를 손님이 직접 고른다 | 2화 화면의 첫 문장, 4화 봉투 값 넣는 곳을 몰라 멈춘 손가락 | 일반 이용 방식(다음 뉴스 "봉투 필요하세요?" 기사) |

## 2. 조심할 것

- **찬반 논쟁을 앞세우지 않는다**: 셀프 계산대 확대는 노조·업계 입장이 갈린다. 원고는 어느 쪽 주장도 화면 글에 옮기지 않고, 민서가 할 수 있는 일을 찾는 이야기로만 썼다. 기계도 악역으로 그리지 않았다(할머니는 끝내 기계를 혼자 쓴다).
- **고령 손님을 서툰 사람으로만 그리지 않는다**: 할머니는 지폐를 끝까지 펴는 자기 방식이 있는 사람이고, 8·9화에서 혼자 해낸다.
- **"본사의 교육" 줄기는 지어낸 것**: 셀프 계산대 돕기 방식을 다른 지점에 가르치는 제도는 확인하지 못했다(지금 6~10편의 설정).
- **회사 이름·숫자는 화면 글에 넣지 않는다**: 마트 이름, 계산대 대수, 감원 인원, 연령. 지금 4편의 "스무 명 넘게"도 원고에서는 뺐다.
- 동네 마트와 대형마트 자료가 섞여 있다. 확인한 보도는 대부분 대형마트다. 민서는 "동네 마트"라 규모가 더 작다는 점만 다르고 이야기의 사정은 같게 썼다.

## 3. 지금 10편과의 관계

10편의 사건과 순서를 그대로 썼다. 화마다 지금 편의 중심 장면이 들어 있고, 바꾼 곳은 다음뿐이다.

- 1화: 할머니를 미리 등장시켰다(꽃무늬 천 가방, 접은 지폐). 지금 1편에는 할머니가 없다.
- 2화: 동료 "정숙 언니"를 새로 넣었다.
- 3화 끝: 장바구니 바닥의 목록 "손주 오는 날"을 새로 넣었다(8화 이사 이유, 10화 이야기로 이어짐).
- 4화: "스무 명 넘게" → "수첩이 금방 이름으로 찼다".
- 5화 끝: 정장 차림의 남자를 넣어 6화 본사 부탁으로 잇는다.
- 7화 끝: 할머니가 "할 말이 있어"로 찾아와 8화 이사로 잇는다.
- 10화: 다른 직원들이 자기 손님 이야기를 꺼내고 민서가 그 이름을 적는다(joy "이름을 불러 드리면 환해지는 손님 얼굴"은 5화에 씀).
