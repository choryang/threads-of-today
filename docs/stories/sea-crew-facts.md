# 로널드 연재: 사실 메모 (초안, 검토용)

- 사람: sea-crew (로널드 · 컨테이너선 선원), 장소 sea (바다 위). 국적은 정하지 않는다.
- 목적: 지금 5편('같이 밥 먹는 곳')을 10화 연재로 늘리기 전에, 배경 중 무엇이 사실이고 무엇을 지어낼지 정한다. 원고는 [sea-crew-serial.md](sea-crew-serial.md).

## 2. 조심할 것

- **코로나 시기는 무겁게 다루지 않는다.** 1화 한 문장의 기억으로만 둔다. 병 이름·연도·숫자를 쓰지 않는다.
- **특정 사고(컨테이너 유실 사고 등)는 쓰지 않는다.** 3화의 넘어지는 막대도 다치는 사람 없이 끝낸다.
- **국적·나라 이름을 쓰지 않는다.** 로널드의 국, 막내의 볶음밥, 갑판수의 빵은 어느 나라 음식인지 밝히지 않는다. 함께 탄 사람은 일(막내·조리장·갑판수·일등항해사)로 부른다.
- **재료 이름을 쓰지 않는다.** 독자와는 "당신의 물건"으로만 잇는다.
- **말이 안 통하는 것을 웃음거리로 쓰지 않는다.** 서툰 공용어는 각자가 애쓰는 모습으로 쓴다.
- 손바닥으로 턴버클을 쳐서 소리로 판단하는 버릇은 지어낸 것이다(실제로는 조임 상태를 눈과 손으로 확인한다는 것까지만 확인).

## 3. 지금 5편과의 관계

지금 5편(줄 점검·당신의 물건 → 처음 보는 선원들과 조용한 식당 → 폭풍과 오해, "빨리 끝나기만" → 고향 국과 막내의 질문 → 돌아가며 만드는 고향 음식, "같이 밥 먹는 곳이 집")을 모두 품는다.
1화 = 1편, 2화 = 2편, 4화 = 3편, 6화 = 4편, 7~10화 = 5편. 새로 더한 줄기는 3화(손 신호와 사고 직전), 5화(폭풍 뒤 점검), 8~9화(혼자 남은 갑판수와 '손 놓지 마'), 10화(종이 뒷면의 레시피와 하선).
joy "항구에 닿아 휴대폰에 답장이 한꺼번에 쏟아지는 순간"은 9화 끝과 10화 첫 문단에 쓴다.
