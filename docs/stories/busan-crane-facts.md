- 사람: busan-crane (진호 · 부산항 크레인 기사), 장소 kr-busan
- 여러 여정에 나오는 사람(항구)이라 화면 글에 재료·물건 이름을 쓰지 않는다("당신의 물건", "상자").
- 지금 stories.ts의 진호 5편과 joy는 건드리지 않았다. 원고는 [busan-crane-serial.md](busan-crane-serial.md).

## 1. 이야기에 쓸 실제 배경

| 사실 | 이야기에 쓰는 법 | 출처 |
|---|---|---|
| 안벽 크레인(배와 부두 사이) 조종실은 지상 수십 m 높이에 있고, 좁은 조종실에서 장비 진동과 높이 때문에 피로가 크며, 궂은 날씨에는 작업이 어렵다 | 차가운 사다리, 발밑 유리 너머의 배, 몸으로 먼저 오는 흔들림. 높이 숫자는 쓰지 않는다 | 뉴스토마토(2025) 북항 자동화 현장 기사 |
| 부산항 일부 터미널은 안벽 크레인을 원격 조종 방식으로 바꾸고 있다. 조종 인력은 육상 사무실로 옮겨 모니터와 조이스틱으로 조종한다. 정부·민간·노조가 전환 속도를 함께 논의 중 | 게시판의 안내문, "조종석이 사무실로 내려온대", 원격 조종실 | 뉴스토마토(2025) |
| 신항의 한 터미널은 야드 크레인을 완전 자동화했고, 안벽 크레인은 운영 사무실에서 사람이 원격으로 직접 조종한다. 원격 조종으로 교대 시간 작업 중단과 높은 곳 작업의 피로·안전 문제가 줄었다고 설명 | 안벽 크레인은 여전히 진호의 손이 움직인다. "마지막 한 뼘은 진호의 몫" | 데일리안 현장 기사 |
| 원격 조종에서는 크레인에 달린 여러 대의 카메라 영상을 실시간으로 보고, 자동 위치 인식·자동 착지·흔들림 방지 기능이 조종을 돕는다. 조종사 한 사람이 여러 대를 맡기도 한다 | 여러 화면, "이렇게 많은 눈으로 상자 하나를 본 적이 없었다", 흔들림을 잡아 주는 장치 | 아이뉴스24(5G 원격 제어 사례, 기업 보도자료 성격) |
| 컨테이너 크레인 기사는 자기 시야와 함께 배·부두 작업자의 신호와 무전에 기대어 일하고, 무전 소통이 부상 위험을 줄인다. 내려앉는 컨테이너에 아래 작업자가 다칠 위험이 있다 | 4화의 물러서는 동료, 6화부터의 무전 목소리, 신호를 맡은 사람 | 미국 OSHA 무전 통신 안내(외국 자료. 국내 기준은 확인하지 못했다) |
| 컨테이너 모서리는 잠금 장치(트위스트록)로 서로 고정하고, 배 위에서 이를 풀고 묶는 작업자가 있다 | 상우가 긴 막대로 잠금 장치를 푸는 장면 | OSHA 안내(트위스트록 언급), 일반 항만 작업 지식 |
| 크레인 기사 한 사람이 한 시간에 컨테이너를 수십 개 옮긴다 | 화면 글에는 쓰지 않는다(people.ts workFact에 이미 있음) | 부산일보 2010 (people.ts의 출처, 이번에 다시 확인하지 않음) |

## 2. 조심할 것

- **원격 조종이 바람을 못 느끼게 한다는 건 확인한 사실이 아니다.** 지금 2·3편의 설정이다. 기사들은 오히려 피로와 위험이 줄었다고 소개된다. 원고에서도 원격 조종을 나쁜 것으로 그리지 않고, 진호가 감을 다시 만드는 이야기로 썼다(8화에 원격으로 센 바람 속 작업을 해낸다).
- **센 바람 속 원격 작업**: 원격 조종이 궂은 날씨에도 작업할 수 있게 한다는 보도는 있지만, 어느 정도 바람까지 하는지는 확인하지 못했다. 원고는 "센 바람"으로만 썼다.
- **옛 조종석을 뜯어내는 일**은 지어낸 것이다. 실제로 개조할 때 조종실을 떼는지는 확인하지 못했다. 걸리면 "조종석 문을 잠근대"로 바꾼다.
- **실제 사고는 쓰지 않는다**: 4화의 흔들림은 다친 사람 없이 끝난다. 실제 항만 사고(검색에 나온 외국 크레인 사고 등)는 배경으로 쓰지 않았다.
- **숫자·회사·기술 이름은 화면 글에 넣지 않는다**: 높이, 카메라 수, 생산성, 통신 기술 이름, 터미널·운영사 이름, 지명. "항구", "이 땅"으로만.
- 고용 불안(원격 조종으로 인력이 줄 수 있다는 논의)은 2화 동료들의 대화 밑에만 깔고 앞세우지 않았다.

## 3. 지금 5편과의 관계

| 지금 편 | 연재에서 |
|---|---|
| 1 높은 조종석, 블록처럼 보이는 컨테이너, 인형뽑기 자랑, 당신의 물건이 이 땅에 처음 닿은 순간 | 1화 그대로(인형뽑기 자랑은 크레용 그림으로도 보여 줌) |
| 2 원격 조종실이 생긴다, 몸으로 느끼던 바람이 진호의 감 | 1화 끝 소식 → 2화 |
| 3 원격 연습 첫날, 컨테이너가 크게 흔들리고 동료가 물러선다, 처음으로 일이 무서웠다 | 3화(연습) + 4화(실제 작업, 끝 문장 그대로) |
| 4 아래 동료가 무전으로 바람을 알려 준다, 아래 사람들이 진호의 눈이 된다 | 5화 끝 전화 → 6화 |
| 5 늘 아래에 사람들이 있었다, 아이에게 크레인 아래 사람들도 그려 달라고 | 7~10화로 늘림(아래로 내려가 이름 묻기, 센 바람의 밤, 마지막 조종석, 새 그림) |

새로 넣은 것: 상우(아래에서 컨테이너를 묶는 동료의 이름), 반장, 아내, 국밥집(joy를 2·5·7·10화에 씀). 시즌이 하나뿐이라 10화가 되면 시즌 2 이름이 필요하다(안: "손을 흔드는 사람들").
