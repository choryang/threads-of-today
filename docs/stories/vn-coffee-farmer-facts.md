## 2. 조심할 것

- **실제 가뭄 해·통계는 쓰지 않는다**: 말라 버린 저수지 수, 죽은 커피 면적, 우물 파는 값은 메모에만. 원고는 "그해 건기는 일찍 왔다"로만 쓴다.
- **특정 회사·단체의 사업 이름을 쓰지 않는다**: 물 아끼기를 가르친 실제 사업(외국 원조 사업, 식품 회사의 농가 교육 등)이 있었지만 이름을 쓰지 않는다. 원고에서는 딸이 학교에서 배워 오는 것으로 지어냈다.
- **"달군 못으로 헌 호스에 구멍 내기"는 지어낸 손재주**다. 실제 점적 관개는 구멍 난 관(점적관)이나 점적기를 쓴다. 집에서 만든 방식으로 읽히게 썼다.
- **이웃 다툼을 나쁜 사람 이야기로 쓰지 않는다**: 롱 아저씨는 펌프를 고친 사정이 있고, 자기 호스를 내주고 양동이로 버틴다(6화).
- **마인의 성별**: 지금 5편에는 성별이 없다. 원고에서는 딸의 엄마로 썼다. 다른 데(카드 그림 등)와 맞지 않으면 "아빠"로 바꿀 수 있다(4화 린의 대사 한 곳).
- **소수 민족 문제·땅 문제 같은 무거운 배경은 쓰지 않는다.**

## 3. 지금 5편과의 관계

| 지금 편 | 새 화 |
|---|---|
| 1편 마당에서 말리기, 냄새로 아는 마름, 당신의 커피 | 1화 |
| 2편 긴 건기, 우물물이 준다, 물 대는 순서로 옆집 아저씨와 첫 큰 다툼 | 1화 끝~3화 |
| 3편 차례가 밀려 밭 끝 나무가 시듦, 길에서 고개를 돌림, "물보다 마음이 먼저 말라" | 3화 끝~4화 |
| 4편 딸이 방울방울 물 대는 법을 배워 옴, 호스가 모자람, 옆집 아저씨가 낡은 호스를 두고 감 | 4화 끝~6화 |
| 5편 물을 덜 쓰고 버팀, 마을이 순서 대신 호스와 방법을 나눔, 연유 커피 두 잔 | 7~10화 |

새로 넣은 것: 이름(딸 린, 롱 아저씨), 담 너머 마르기 내기, 차례표와 마을 회의, 파란 테이프, 하얀 꽃과 비.
