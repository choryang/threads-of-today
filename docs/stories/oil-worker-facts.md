## 2. 조심할 것

- **여성 현장 기술자를 '특별한 구경거리'로 쓰지 않는다**: 무니라가 드문 처지라는 건 숙소의 방 하나로만 보이고, 이야기의 중심은 일을 잘 아는 사람이라는 것. 차별 장면은 2화의 "웃음을 참는 옆자리 사람" 정도로 두고, 그 웃음도 '옛날 방식'에 대한 것으로 썼다.
- **실제 회사·인물 이름은 쓰지 않는다**: 사우디 최대 석유 회사, 첫 여성 공학자로 보도된 사람들의 이름은 메모에만 둔다. 화면 글에서는 "본사", "현장"만.
- **나라 이름은 화면 글에 쓰지 않았다**: 사막·모래 언덕만으로 장소가 보인다. 숫자도 없다("사흘", "한 번 더" 같은 생활 표현만).
- **무니라는 여러 물건에 나오는 사람**이라 재료 이름을 쓰지 않는다. 지금 1편의 "당신이 쓴 플라스틱" → "당신 곁에 있는 물건"(1화), 마지막은 "당신의 물건이 시작된 곳에도"(10화).
- **고장의 결과를 사고로 키우지 않는다**: 펌프가 멈추고 밤샘 수리하는 정도. 화재·인명 사고 같은 무거운 사건은 쓰지 않는다.
- **'소리로 고장을 맞힌다'의 과장**: 실제 예지 정비의 핵심은 센서 진동 분석이고, 귀로 듣기는 오래된 보조 방법이다. 화면이 모두 정상인데 사람만 들었다는 건 이야기의 설정(지어낸 것). 그래서 8~10화에서 "빗나간 것까지 같이 보여 줘야 믿는다"로 균형을 잡았다.

## 3. 지금 10편과의 관계

지금 10편의 사건(낯선 소리 → 사흘 뒤 멈춤 → 선배가 다시 읽은 보고서와 기록장 → 신입 / 본사 발표·도시 사무실 → 동생의 낙방 → "숫자로 보여 달라" → 동생의 그래프 → 발표, 현장에 남기)과 순서를 그대로 두고 장면을 늘렸다.
바꾼 것: 1편의 "플라스틱" 표현, 이름 없던 선배·동생에게 이름(하미드, 누라), 2편의 "기분 탓일 거라는 말"을 무니라 자신의 속생각으로. 새로 심은 것: 쇠막대, 손등의 번호, 지운 몇 줄, 회색 점(빗나간 소리).
