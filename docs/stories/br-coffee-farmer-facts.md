# 주앙 연재: 사실 메모 (초안, 검토용)

- 사람: br-coffee-farmer (주앙 · 아라비카 커피 농부), 장소 br-mg (브라질 미나스제라이스)
- 목적: 실제 배경 위에 지어낸 인물의 10화 연재를 쓰기 전에, 무엇이 사실이고 무엇을 지어낼지 정한다. 원고는 [br-coffee-farmer-serial.md](br-coffee-farmer-serial.md).

## 1. 이야기에 쓸 실제 배경

| 사실 | 이야기에 쓰는 법 | 출처 |
|---|---|---|
| 브라질에서는 나무 줄을 올라타고 가지를 흔들어 열매를 떨구는 수확기가 널리 쓰인다. 경사 30%까지 다니는 기계도 만들었지만, 경사가 급할수록 일이 느려지고 돌아 나가는 데 시간을 많이 쓴다 | 1화 기계 수확, 4화 기계가 구석 밭에서 멈춘다, 5화 "흙을 조금 깎으면 비스듬히 들어올 수 있다" | Santinato 외, Revista Caatinga(2016) |
| 미나스제라이스 남부 커피 밭 가운데 약 3분의 1은 기계화에 맞지 않아 손으로만 딴다(한 연구의 추정) | 4·10화 구석 밭과 바위 사이는 손으로 | Santinato 외 관련 논문(Redalyc) |
| 남부 미나스의 수확철은 대략 5~8월이고, 계절 일꾼을 부른다. 비탈에서 커피를 기르는 가족 농가는 기계화가 어려워 손 일이 계속 필요하다 | 2화 수확철마다 일꾼을 이끌고 오는 세바스치앙 | UFMG 계절 일꾼 연구(Trabalho & Educação, 2018) |
| 손 수확(데히사): 나무 밑에 천을 깔고 가지를 훑어 열매를 떨군 뒤, 체로 까불러(아바나썽) 잎·잔가지·흙을 골라낸다 | 5화 천과 체 | Embrapa 수확 안내 자료, UFV·IF Sul de Minas 자료 |
| 수확철은 남반구 겨울이라 서리가 내리는 해가 있다. 2021년 7월 미나스제라이스 등에 큰 서리가 내려 잎과 가지가 타 죽은 밭이 많았다 | 5화 "오늘 밤은 춥겠어요", 6화 서리. 연도·피해 규모는 쓰지 않는다 | Daily Coffee News(2021), Datamar News(2021) |
| 서리 뒤에는 비가 와서 나무가 얼마나 살아나는지 보고 나서 어떻게 자를지 정하라는 조언이 있었다. 심하면 줄기를 땅 가까이 잘라 다시 키우고, 죽은 나무를 뽑고 곡물로 바꾸는 농가도 있었다 | 7화 "비가 와야 어디까지 잘라야 할지 보인다", 옆 농장은 다른 작물 이야기, 8화 밑동 가까이 자르기 | Reuters 보도 인용(Fuller Treacy Money, Hospitality Ireland, 2021) |
| 차가운 공기는 무거워 바람 없는 밤 낮고 움푹한 땅에 고이고, 그런 곳이 서리를 더 심하게 맞는다 | 6화 "아래 움푹한 밭부터" | 일반 기상 상식(복사 서리). 이번 검색에서 커피 자료로 따로 확인하지 못했다 |
| 땅 가까이 자른 커피 나무는 그루터기에서 새 순이 올라오고, 몇 개만 남겨 키운다. 다시 열매를 맺기까지 몇 해가 걸린다 | 8화 연두색 순, 9화 순 고르기, 10화 "언젠가 저 그루터기에서" | 재배 일반(콜롬비아 소코와 같은 원리, isabel-facts.md의 Cenicafé 자료). 브라질 자료로 따로 확인하지 못했다 |

## 2. 조심할 것

- **실제 서리 해와 피해 규모는 쓰지 않는다**: 2021년, 피해 면적, 가격 급등 같은 사실은 메모에만. 원고는 "그 밤", "서리"로만 쓰고 큰 재난처럼 그리지 않는다. 한 농장 구석의 일로 둔다.
- **계절 일꾼의 강제 노동 문제**: 브라질 커피 수확 일꾼의 노예 노동 사례를 다룬 보도(Public Eye·Repórter Brasil, 2025)가 있다. 무거운 실제 문제라 배경으로 쓰지 않는다. 세바스치앙은 오래 같은 농장과 일한 일꾼 반장으로, 존중받는 사람으로 쓴다. 기계화로 일자리가 주는 것은 지금 2·3편 그대로 담담하게.
- **지금 2편의 "이십 년 넘게"는 숫자다**: 원고에서는 "오랜 세월, 주앙의 아버지 때부터"로 바꿨다. 앱에 넣을 때 지금 2편도 같은 표현으로 바꿀지 정해야 한다.
- **기계를 나쁘게 그리지 않는다**: 기사도 마지막 저녁에 함께 고기를 먹는다. 기계와 사람이 밭을 나눠 맡는 것으로 끝낸다.
- 실제 농장·협동조합·기계 회사 이름은 쓰지 않았다. "판매원"은 지어낸 인물.

## 3. 지금 5편과의 관계

| 지금 편 | 새 화 |
|---|---|
| 1편 끝이 안 보이는 밭, 걸으며 딸 날 정하기 | 1화 |
| 2편 새 수확기, 세바스치앙을 부르지 않기로 | 1화 끝~2화 |
| 3편 직접 전함, 고개만 끄덕임, 잠 못 이룬 밤, 텅 빈 밭 | 3화 |
| 4편 기계가 가파른 구석 밭에 못 들어감, 전화, 다음 날 아침 와서 기계 길을 짚어 줌 | 4~5화 |
| (새로) 서리 내린 해: 기계가 못 보는 것이 넓어진다 | 6~8화 |
| 5편 반장 자리 부탁, "넓은 밭일수록 한 사람의 눈이 더 귀하다" | 9~10화 |

새로 넣은 것: 밀짚모자와 휘파람, 장부, 할아버지의 구석 밭, 서리와 그루터기, 기사.
