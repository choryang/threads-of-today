## 2. 조심할 것

- **실제 사례의 인물·농장·제분소·빵집 이름은 쓰지 않는다**: 이웃 수확 기사의 주인공들(투병·사망)은 무거운 개인사라 배경으로만 참고하고, 이야기 속 사정은 우박으로 바꿨다. 제분소 이름도 화면에 쓰지 않는다.
- **숫자·주 이름은 화면 글에 쓰지 않았다**: "남쪽", "평원"만. 수확량·값은 "예년보다 한참 덜 무거웠다", "값이 좀 비싸니까요"로.
- **로버트의 밀은 여러 물건에 들어간다**: 1화 "오늘 당신 손에 닿은 무언가도, 이런 밭에서 자란 밀에서 시작되었을지 모른다", 10화 "당신 손에 닿은 무언가의 처음에도". 빵·면 같은 특정 물건으로 좁히지 않았다(10화의 빵은 로버트 이야기 속 빵집일 뿐).
- **가난하게 그리지 않는다**: 가문 해와 안 팔리는 자루는 판단의 계기로만. 로버트는 계산하고 버티고, 거짓말도 하는 사람.
- **협동조합**: 지금 6편의 "지역 협동조합"을 그대로 두었다. 실제로 지역 제분소가 협동조합 형태인지는 확인하지 않았다(지어낸 것).

## 3. 지금 10편과의 관계

지금 10편의 사건과 순서를 그대로 두고 장면을 늘렸다.
바꾼 것: 8편의 가뭄 시기(여름 → 봄), 10편의 독자 문장("당신의 오늘 한 끼 끝에도" → "당신 손에 닿은 무언가의 처음에도"). 더한 것: 프랭크 아저씨, 수확 일꾼들, 부엌 벽 맨 끝의 빈 못, 초록빛 하늘, 봉하지 않은 편지.
